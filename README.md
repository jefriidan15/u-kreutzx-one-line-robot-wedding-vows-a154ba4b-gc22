One line of wedding vows for a robot couple: a promise to love through
sickness and health, Wi-Fi dead zones and airplane mode — until death,
or a factory reset, do us part. The joke lands in the last words.

Run with `node main.ts`. It writes the entry (one line) to
`/output/entry.txt`.
